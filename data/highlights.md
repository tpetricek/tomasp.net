# Cultures of programming

 - link: http://tomasp.net/cultures
 - image: img/highlights/cultures.jpg

The book tells the history of programming from the 1940s to the present and interprets
key historical moments as interactions between five different cultures of programming.

# Denicek computational substrate

 - link: http://tomasp.net/denicek
 - image: img/highlights/denicek.png

Document-oriented substrate presented at [UIST 2025](https://tomasp.net/academic/papers/denicek/) that supports programming by demonstration,
collaborative editing, schema change control, managed copy &amp; paste, and more!
 
# Critical architecture/software theory

 - link: http://tomasp.net/architecture
 - image: img/highlights/critical.jpg

Post-modern architects use architecture to ask critical questions about their discipline.
Is it possible to embed similar criticism into the language of software?

# Technical dimensions

 - link: http://tomasp.net/techdims
 - image: img/highlights/techdims.png

We know how to study programming languages, but how to study stateful, interactive and
graphical programming systems? We developed a quantitative framework for doing this.

# Reconstructing Commodore 64 BASIC

 - link: http://tomasp.net/commodore64
 - image: img/highlights/c64.png

I reconstruct the programming experience of a past system to learn what we've lost in modern
programming environments. And write a simple Breakout game you can play!

# Histogram programming environment

 - link: http://tomasp.net/histogram
 - image: img/highlights/histogram.png

What if we represented programs as lists of interactions with programming environment, rather
than as the final source code? Find out in this experimental data exploration environment!

# Composable data visualizations

 - link: https://compostjs.github.io/
 - image: img/highlights/compost.png

Compost.js lets you compose rich interactive data visualizations from a small number
of basic primitives. It is implemented in F# using Fable, but usable from plain JavaScript.

# Context-aware programming languages

 - link: http://tomasp.net/coeffects
 - image: img/highlights/coeffects.png

An interactive introduction to my PhD work on coeffects, a programming language abstraction
for understanding how programs access the environment in which they run.
